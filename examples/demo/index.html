Acme — demo product

Test page with the Supportal widget

The support widget is embedded in the page — the 💬 button at the bottom-left. Open it and type a message.

Telegram is mocked: nothing goes to a real bot. To reply "as the operator", open the operator console (a mock Telegram topic) and reply — the reply reaches the widget in ~4s (polling). There you can also edit or recall a reply and see the change sync into the widget.

Attachments & i18n: use the 📎 button to send an image or file (shown both ways). The widget copy here is Spanish — supplied by /support/config as a strings override to demonstrate localization (English is the default).

The widget token is minted by the demo endpoint POST /support/config; the widget API is under /support-api/v1/widget/* (in production a reverse-proxy serves this path).
