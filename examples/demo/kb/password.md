# Сброс пароля

Чтобы сбросить пароль:

1. Откройте страницу входа и нажмите **«Забыли пароль?»**.
2. Укажите адрес электронной почты вашей учётной записи.
3. Проверьте почту (и папку «Спам») и перейдите по присланной ссылке.
4. Задайте новый пароль. Ссылка действует 60 минут.

Если письмо не пришло, проверьте правильность адреса и попробуйте ещё раз.
